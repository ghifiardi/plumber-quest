# Store listing copy — Plumber Quest

Ready-to-paste store copy for the App Store and Google Play. **Positioning:** an
original retro platformer for a general audience (a **Games** category, **not**
Apple Kids / Play Families). Online presence/callouts are described as **optional**
and privacy-safe. No "Mario"/Nintendo references (100% original assets).

> Player-facing scope of the current build: the classic 6-level platformer with
> crisp pixel rendering + game-feel juice and an optional online presence mode.
> The ECS engine/editor/demo levels are developer surfaces (URL-gated) and are
> **not** described here because they aren't part of the player flow.

## Notes for submission

- **Category:** Games (App Store: Arcade or Action; Play: Arcade / Action). **Not**
  Apple Kids or Play "Designed for Families."
- **Privacy:** the only data sharing is the optional online mode (pseudonymous
  installation ID + random handle + online status + preset callouts + level
  milestones, via Supabase, which also processes IP). No tracking, no PII, no
  login. See `docs/privacy-policy.html` and the Data safety guidance in
  `docs/PLAY_STORE.md`.
- Keep listing copy free of "kids"/"for children" positioning to stay consistent
  with the Games-category, online-enabled decision.
