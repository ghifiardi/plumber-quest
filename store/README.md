# Play Store listing assets

Graphics for the Google Play store listing. See
[../docs/PLAY_STORE.md](../docs/PLAY_STORE.md) for where each one goes.

| File | Use | Size |
| --- | --- | --- |
| `play-store-icon-512.png` | App icon on the store listing | 512×512 |
| `play-feature-graphic-1024x500.png` | Feature graphic (banner) | 1024×500 |

You still need **phone screenshots** (at least 2): run the game and capture a
few frames. Regenerate these graphics any time from the source artwork in
`../resources/icon.svg`.
